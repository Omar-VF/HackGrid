## 🛠️ Technology Stack Overview

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS with dark glassmorphism, HTML5 Canvas, Recharts, Lucide Icons.
- **Vision & Autonomous Pipeline**: Next.js API Route Handlers / lightweight Python CV bridge with computer vision model runner and Open-Meteo micro-climate weather integration.
- **Prescriptive Engine**: Deterministic EPA/EU chemical formulation and automated tractor spray work-order dispatch generator.
